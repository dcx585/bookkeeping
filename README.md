# 记账

本地优先的个人记账应用，单文件 HTML 运行，数据存储在浏览器 localStorage。

## 功能

- 💰 支出 / 收入 / 转账三类交易
- 📊 月度统计 & 分类占比
- 📋 原预算 vs 实际扣款对比
- 🔁 固定支出模板 + 快捷记账
- 🔍 交易搜索
- 📱 自定义账户管理
- 📤 CSV 导出 / JSON 备份恢复
- 🎨 自定义背景
- 🧮 内置计算器（可引用账户余额）

## 使用

直接用浏览器打开 `app.html`。

首次打开显示启动动画，上滑进入主界面。

## 技术栈

- 纯 HTML/CSS/JavaScript，零依赖
- localStorage 持久化
- 移动端适配 420px
